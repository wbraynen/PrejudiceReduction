# Modeling Prejudice Reduction

Software for an agent-based game-theoretic model of the contact hypothesis of prejudice reduction, to accompany "Modeling Prejudice Reduction," in the Handbook of Computational Social Psychology, adapted from Public Affairs Quarterly 19 (2) 2005.

## Running the simulation

https://wbraynen.github.io/PrejudiceReduction/

You can run the simulation there, as well as see unversioned source code and pseudo-code.

## Versioned source code

See the `ptft.nlogo` file in the NetLogo folder.  Instructions for how to run it can be found at [https://www.netlogoweb.org](https://www.netlogoweb.org).

## JavaScript version

See the `docs` folder.  The `index.html` file contains the JavaScript code.  For a more user-friendly way to view the source code, however, see "Running the Simulation" above.

(I would have put it in a JavaScript folder, but this way I can automatically publish to GitHub pages on a git-push without exposing the rest of my repo through that URL; hence the strange naming convention:)
